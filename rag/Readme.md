# Rag

[Documentación Spring AI rag](https://docs.spring.io/spring-ai/reference/api/retrieval-augmented-generation.html)

Basicamente el uso de RAG, esta pensando para extraer y trocear información, guardarla en bases de datos vectoriales, para posteriormente poder indicarle a los agentes donde buscar información para resolver una preguntar y que este sea similar a lo que se guardo anteriormente en la base de datos vectorial.

## Ejemplo

Para el ejemplo vamos a realizar un ETL de datos sobre contabilidad y luego vamos implementar un chat donde preguntemos información acerca de la contabilidad.
